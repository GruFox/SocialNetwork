App SocialNetwork - консольное приложение с трехуровневой архитектурой:

- BLL (Business Logic Layer)
- DAL (Data Access Layer)
- PLL (Presentation Logic Layer)

PLL в дальнейшем может стать веб-сайтом или мобильным приложением.
BLL не зависит от уровня презентации (PLL).
Благодаря Repository приложение не привязано к конкретной базе, в любой момент можно изменить место хранения данных.
В данном приложении хранение данных реализовано с помощью SQLite.
